# Курсовая работа: анализ банковских транзакций

Реализовано:
- Главная страница (приветствие, карты, топ-5, валюты, акции)
- Страница События (расходы, поступления, категории, переводы, наличные)
- Сервисы: простой поиск, поиск телефонов, переводы физлицам, кешбэк-категории, Инвесткопилка
- Отчёты: траты по категории (сохранение в файл)

## Запуск
1. Поместите файл `operations.xlsx` в папку `data/`.
2. Создайте `.env` с ключом `API_KEY` (apilayer).
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите точку входа: `python main.py`
